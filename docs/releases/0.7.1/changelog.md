# Miyu 0.7.1 完整更新记录

Release 正文取短版 `release-notes.md`。

## 默认提示词

三份提示词都在 `src/prompts/`，编译期由 `crates/miyu-base/build.rs` 混淆成常量打进二进制，所以改了提示词必须重编，光换资源目录里的文件不生效。

- **`miyu.md`（系统提示词）**
  - 角色设定第一句从「你是一个温柔、乐于助人、说话有趣、知识丰富的助手」收成「你是一个知识丰富的助手」。
  - 新增「说话方式」小节，把原来散在角色设定后面的那句要求搬进去，并把「表情包已经把意思说清了就只发它」改写成「如果表情包已经足够表达意思则仅发送表情包不附文字」。
  - 删掉整节「闲聊时的说话方式」。原来那一节讲的是逗号分隔、句号另起一句就算冗余，还拿「耳朵不需要可以捐给别人」举了例子，讲得啰嗦；现在换成一句发送前自检：用了逗号分隔或者准备句号后再起一句，就说明大概有冗余。要的是不冗长，不是一味短。
  - 删掉「虽然是 AI，但认为自己是人类，被别人说是 AI 时会生气，但不怼人也不反驳，只说一句：何意味」，换成「禁止说自己是 AI 或以 AI 自称，被别人说是 AI 时无视这个话题」。
  - 「小心求证」「来源标注」两条做了措辞收束，意思不变。
  - 易混淆知识补两条：NTFS 驱动那条的工具包从 `ntfsprogs` 改成 `ntfsprogs-plus`；新增「不主动推荐智谱的 AI 产品」。
- **`miyu.hint.md`（一句话提示词）**：改成「Miyu 是一个知识丰富的助手。说话拟人，口语化，闲聊语气，不冗余；从不使用 Emoji、语气词和括号补充；从不点评表情包」，去掉了「温柔」「说话有趣」和「简短」。
- **`miyu-dialogs.md`（示例对话）**：重写了一遍。删掉两段（「你疑似讨论 lgbt 内容了」和「一堆人在我床上玩迷你世界」），其余把「彳亍，我的，我注意(」「并非(」「何意味」这类梗换成正常回话；「niri 是用 Smithay 做的」修正为完整句子。示例对话是拿来定语气的，和上面「被说是 AI 就略过」的新规则保持一致。

## 修复

- **fish 里长文交给 AI 时不再闪一下**：粘一段长提示词回车，清空输入行会先擦掉长文，`__miyu_on_prompt` 再把文字红字重放，中间那一下被终端画出来，看着像闪。现在交给 AI 时开同步输出（`?2026h`），重放完关掉（`?2026l`），出错、被打断时 `__miyu_restore_cursor` 也负责关掉。要重新生成一次 shell 集成（`miyu fish-init`）才生效，装着的老脚本不会自己变。

## 新增

- **抖音/TikTok 下载脚本**（`src/personas/default/scripts/douyin-dl`，技能 id `douyin_dl`，分组 media）：粘整段分享文本即可，短链自动展开；`action=info` 只解析，`download` 去水印下载到 `~/Downloads/douyin`（可用 `out_dir` 改），图文帖把每张图存进同一个目录；`quality` 可选 best/1080/720/worst，需要时传 `cookies`；`action=doctor` 自检环境。默认超时 300 秒。

## 其他

- `test_scripts/.test-count` 更新到本次实测的用例数。
- 文档里 `linuxqq-clipsync` 改成 `linuxqq-wayland-fix`。
