# Miyu 0.6.2

她可以自己把内容渲成图片发进群了——表格、结构化说明和 mermaid 流程图画进同一张图。表情包接近真人手感：够表达意思时不再硬配一句话，单独成条发送，尺寸和 QQ 自带表情一致。工具面瘦了 29%，空会话从 18.3k token 降到 13.0k。另外修掉两个会咬人的：opencode Zen 下读文件死循环，以及同一个家目录被起两个 daemon。

三十多条改动的完整记录在[这儿](https://github.com/SHORiN-KiWATA/miyu-agent/blob/v0.6.2/docs/releases/0.6.2/changelog.md)。

## 新增

- **`render_image`**：把 markdown 渲成成品图片发到通讯平台。表格、结构化说明、mermaid 流程图（画进正文同一张图，不另起一张），也可以直接指定一个 `.md` 文件——文件内容不占对话额度。只生成，发哪张由她决定。
- **`query_session_token_usage`**：当前上下文占窗口多少、本会话累计消耗（含派出的子代理）、聊了几轮。原来模型只查得到全局总账。
- **QQ 会话专属配置 · 概率主动回复抽样概率**：给单个群或单个人定话痨程度，覆盖插件设置里的全局概率。留空跟随全局。
- 内置表情包 +2，共 38 张。
- **技能带路的脚本不进常驻工具清单**：脚本住在 `skills/<技能名>/scripts/` 里就由技能带路，照常注册和调用，但不占 tools 数组。
- 发布构建支持 `--download-cache`，锁定归档不再每次重下。

## 变更

- **工具面 token −29%**：空会话 18,325 → 12,964；同一个问题供应商侧计的输入 token 21,105 → 15,133。功能一项没减，把「调用之后才用得上」的字段说明、分页边界、输出格式挪进了工具自己的返回。
- **表情包够表达意思时只发表情**，不再强行配一句话。
- **表情包单独成一条消息**：与正文分开发，先后顺序随机，间隔 0.4–1.2 秒；表情那条不带引用和 @。生成的图片仍与正文同条。
- **表情包按 sticker 尺寸发**，与 QQ 自带表情一致。不重新压缩，画质与动图不受影响。
- **搜图只负责搜到并下载**，不再自动发送或自动贴在终端；发哪几张由她挑。`print_image` 改为支持批量，不限张数。
- 六件低频工具改由技能带路，不占常驻清单：机票比价、酒店比价（旅游攻略）、哔哩哔哩直播控制、DeepSeek 服务状态、`manage_script`、`manage_skill`（script-creator / skill-creator）。
- **语音模型改为机器级共享**（`~/.cache/miyu/voice-models`）：换家目录、多用户、跑测试沙箱不再各下一份 190MB。已下载的不受影响。
- 后台任务完成报告从用户气泡改成通知行，排队期间不再占位。
- 终端里的流程图底色 `#FFFFFF` → `#F0F0F2`；控制台的流程图改用主题色变量，底色透明，跟随主题与 matugen 配色。
- 成品图里的流程图底色跟随页面主题。
- 默认多模态模型 `mimo-v2.5-free` → `mimo-v2.6-flash-free`（仅在未配置多模态模型池时生效）。
- `query_token_usage` → `query_system_token_usage`。老会话历史里的旧名会显示为未知工具。
- 配置项「概率主动回复」→「开关概率主动回复」。

## 修复

- **opencode Zen 下读文件死循环**：上个版本为通过客户端识别加的工具名映射，回程用了一个早已废弃的名字，把正确的 `read` 改写成不存在的 `read_file`。跑命令不受影响。现已加构建期检查，映射表里出现不存在的工具名直接编译失败。
- **同一个家目录会起两个 daemon**：`MIYU_HOME` 一处设了一处没设（即便指向同一个默认目录）就会被当成两套环境，各自再拉起一个语音进程抢同一个麦克风，白占约 80MB 内存。
- **单例锁的瞬时竞争被误判成「daemon 在跑」**，导致家目录搬迁与回滚静默失败。改为连续观察一小段时间。
- 回合以报错收场时，footer 的声波动画冻在最后一帧。取消那条路此前已修，报错和连接中断这两条漏了。
- **被打断的回合丢失过程回放**：只有正常结束的回合留快照，重开终端只剩一句「已中断」。现在打断也存快照，投影改为拼接所有分段。已有会话会在重开时从库里补回。
- 关闭终端会取消正在跟进后台任务的回合。
- 空会话里拖选会把输入框左侧的 `┃` 选进剪贴板（大厅星空画在输入框左边，原判据只认「竖线在行首」）。
- 指针移出终端窗口后，悬浮提亮残留在屏上。
- 设置「启用的功能」页中英混杂——该页此前直接显示写给模型看的英文说明。19 个内置脚本与 6 份技能补了中文说明。
- 设置「启用的功能」页里脚本、技能、MCP 三类行按回车无响应，底部却提示「⏎ 设置」。现在按回车看完整说明。
- `travel-planner` 技能从未登记进 `BUILTIN_SKILLS`，任何人都加载不到。已加构建期检查。
- 记账工具谎报每个账本都有「现金 / 电子支付 / 交通卡 / 信用卡 / 银行卡」——那只是新建账本的默认账户。

## 移除

- 工具：查询进程占用、查询环境变量、查看系统信息、Fcitx5 Wiki 查询、查询大模型 API 额度。前四件一条命令或一次搜索即可替代，最后一件只支持 DeepSeek 和 OpenRouter 两家。
- 配置项：搜图的「自动预览」「默认预览数量」；「查询大模型 API 额度」的设置页。旧字段保留在配置文件里不会报错。

## 升级注意

- 要 `miyu daemon restart`。已经开着的终端得重开才用上新前端，控制台刷新一下页面。
- 升级后第一次请求会重建一次提示缓存：工具清单瘦了 29%，前缀跟着变了。之后照常命中。
- `query_token_usage` 改名成 `query_system_token_usage`。老会话的历史里留着旧名，她照着模仿会撞一次错再改口，新会话不受影响。
- 搜图的「自动预览」「默认预览数量」两个配置项作废，留在配置文件里不会报错。「查询大模型 API 额度」的设置页一并移除。
- 语音模型改成机器级共享（`~/.cache/miyu/voice-models`）。已经下过的不会重下也不会搬走。
- 配置项「概率主动回复」改名为「开关概率主动回复」，值不变。

## 下载与安装

附件是 Linux x86_64 的六个安装包。主包自带字体、语义模型、表情、脚本、默认知识库和许可证；语音是可选包，版本要和主包一致，已经装了语音的请在同一条命令里写上两个包。

| 发行版 | 主包 | 可选语音包 |
| --- | --- | --- |
| Arch Linux | `miyu-0.6.2-1-x86_64.pkg.tar.zst` | `miyu-voice-0.6.2-1-x86_64.pkg.tar.zst` |
| Debian 13 / Ubuntu 24.04 LTS 及更新 / Linux Mint 22 | `miyu_0.6.2-1_amd64.deb` | `miyu-voice_0.6.2-1_amd64.deb` |
| Fedora 44 | `miyu-0.6.2-1.fc44.x86_64.rpm` | `miyu-voice-0.6.2-1.fc44.x86_64.rpm` |

```bash
# Arch Linux
sudo pacman -U ./miyu-0.6.2-1-x86_64.pkg.tar.zst

# Debian / Ubuntu / Linux Mint
sudo apt install ./miyu_0.6.2-1_amd64.deb

# Fedora 44
sudo dnf install ./miyu-0.6.2-1.fc44.x86_64.rpm
```

这六个包都在 Arch、Debian 13、Ubuntu 24.04、Ubuntu 26.04、Linux Mint 22.3、Fedora 44 的干净容器里装过一遍，每个都让她真回了一句话，42 项必需检查全过。Arch 也可以走 AUR：`miyu` / `miyu-voice` 是二进制包装，`miyu-git` 从源码构建。
