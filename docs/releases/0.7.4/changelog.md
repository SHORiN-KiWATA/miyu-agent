# Miyu 0.7.4 完整更新记录

Release 正文取短版 `release-notes.md`。

## 默认提示词

照盲测结果再调一轮说话方式（第一版 41% 被当成真人，第二版 48%）。提示词编在二进制里，要换新二进制、重启 daemon 才生效。

- **`miyu.md`（系统提示词）**
  - 「说话方式」加一条：接话多半是表个态、起个哄、好奇问一句，或者说说自己，不是给人讲解；别人没问「是什么」「怎么弄」，就不科普、不纠正细节、不给方案。
  - 短反应的例子补上「啊？」「绷」「真的假的」，并写明差不多一半的话在七个字以内。
- **`miyu-dialogs.md`（示例对话）**：末尾补 5 组短示范——装好驱动回「终于」、晒主题回「好看」、熬夜配置回「配好了吗」、「我也用 arch」回「握手」、听说功能被删回「真的假的」。
