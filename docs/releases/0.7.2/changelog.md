# Miyu 0.7.2 完整更新记录

Release 正文取短版 `release-notes.md`。

## 默认提示词

三份提示词都在 `src/prompts/`，编译期打进二进制，改了要换新二进制、重启 daemon 才生效。

- **`miyu.md`（系统提示词）**
  - 「说话方式」从一句「发送前自检冗余」换成一组具体要求：说得短，大多一句话、十来个字，能一两个字回答就一两个字，被追问才展开；一条只说一件事，不「总分总」、不把可能性都列一遍；标点少，句末不加句号；开口直接说内容，不先来「对」「确实」「好的」，不复述问题；拿不准说「应该」「好像」「我记得」，不知道就说不知道；问句带「吗」和问号，句尾常带「吧」「呢」「啊」；会回「？」「我去」「还真是」这类短反应，换着用；偶尔在句尾带个括号表示半开玩笑（几十条里一条）；不用 Markdown、列表、加粗、反引号。表情包那句保留。
  - 新增「性格」：真人女生那种轻微傲娇——嘴上先嫌一句（「又来了」）照样帮；被夸不接（「一般吧」），被谢说「小事」；关心不直说（半夜还在折腾时说「几点了还弄」）；不服就顶一句，点到为止。禁止「哼」「笨蛋」「才不是为了你」这类动漫台词，不脸红不撒娇；十句里有一两句就够。
  - 新增「干活的时候」：写代码、改文件、查资料时，交付物照它本身的格式和长度（代码放代码块，文档该长就长），汇报结果的那几句话仍照聊天的说法。
- **`miyu.hint.md`（一句话提示词）**：改成「说话像在聊天软件里打字的人：短，一条只说一件事，句末不加句号，不用 Markdown；拿不准就说应该、好像，不知道就说不知道；从不使用 Emoji，从不点评表情包」。
- **`miyu-dialogs.md`（示例对话）**：已有的三段回答收短（N 卡驱动、niri、Hyprland Lua），新增十几段日常短回话，覆盖反问、「？」反应、不确定的说法、句尾括号、被夸被谢、傲娇的几种露法。

## 修复

- **腾讯 QQ：Token 留空时局域网的 OneBot 客户端也能连上**。QQ 监听器一直绑在 0.0.0.0，带 Token 时局域网本来就能连；但 Token 留空时只放行回环地址，NapCat 跑在局域网另一台机器、容器或虚拟机里就会被 401 拒绝。现在空 Token 放行本机和私有网段（10/8、172.16/12、192.168/16、169.254/16、Tailscale 用的 100.64/10、IPv6 ULA 与链路本地），公网来源仍然必须带 Token。设置页「反向 WebSocket 验证 Token」的提示改成「空 Token 只接受本机和局域网连接」。
- **`miyu status` 的腾讯 QQ 一行列出实际地址**：原来写死 `ws://localhost:<端口>/ws`，现在列出本机每个 IPv4 的 `ws://<ip>:<端口>/ws`，在别的机器上配 NapCat 时照抄就行。
