# 01 · 快速开始

> ⚠️ **临时版本提示**：本文档由 DeepSeek 根据当前 Miyu 源码逐行整理，属于临时参考版本；正式版文档仍在施工中，内容可能与最新代码存在出入。请以 `miyu -h`、`miyu config`、仓库 README 及源码为准。

## 1. 安装

### Arch Linux（推荐）

```bash
yay -S miyu
```

AUR 上有两个包：

| 包名 | 说明 |
|---|---|
| `miyu` | 下载 GitHub Release 预编译包 + Noto 字体，安装快 |
| `miyu-git` | 从最新 main 源码编译，更新最激进 |

依赖说明：Miyu 运行需要 `chafa`（终端显示图片）、`ripgrep`（文件搜索）、`alsa-lib`（闹钟声音）。可选的 `fish/bash/zsh` 用于终端无缝集成，`git` 用于更新默认知识库。

### 从源码构建

```bash
git clone https://github.com/SHORiN-KiWATA/Miyu.git
cd Miyu
cargo build --release
# 可执行文件在 target/release/miyu
```

Rust 版本要求：1.89+（见 `Cargo.toml`）。

## 2. 第一次运行

```bash
miyu init        # 创建默认配置和目录
miyu -h          # 看帮助
miyu paths       # 看所有数据/配置/缓存路径
```

其实**不运行 init 也行**：绝大多数命令首次执行时会自动初始化。例外是 `paths`、shell hook 安装、`import` 等命令可以不用先初始化。

首次初始化会做这些事（对应 `cli/setup.rs` 的 `run_init`）：

1. 创建 `~/.miyu/{config,data,cache,state}` 等目录（权限 0700）。
2. 写入默认配置 `config.jsonc`（JSONC，允许注释）。
3. 写入默认人格文件 `prompts/system-prompt.md`、`identities/user-identity.md`（开发模式提示词 `dev-prompt.md` 默认为空、不预先生成）。
4. 导入默认知识库（打包进系统时的 Linux 日用知识，失败可跳过）。
5. 创建技能、脚本、表情包等用户目录。

## 2.1 新手引导（OOBE）

第一次裸运行 `miyu`（配置里 `oobe_done` 还是 false）会先进一个五屏的引导，`miyu oobe` 可以随时手动再跑：

1. **人格**：用内置的 Miyu，或自己捏一个（名字 + 可留空的人格提示词，落在 `prompts/<名字>.md` 并激活）。
2. **功能**：勾选要用的内置功能、脚本、技能（记忆 / 知识库 / MCP / 技能本身常开，不摆出来），落在该人格的 `persona.toml`。内置脚本与内置技能对自定义人格也列出来，默认不勾（保持纯净），勾了才挂。
3. **认识你**：一句自述，落在 `profile.md`。
4. **终端集成**：探到 fish / bash / zsh 就问装不装 shell hook；已装过的标「保持」，不重复写。
5. **接模型**：借本机已登录的 `claude` / `codex` / `agy`（探到才列）；常用供应商预设（opencode Zen 免 key、OpenCode Go、OpenAI、Anthropic、DeepSeek、Gemini、OpenRouter、Xiaomi MiMo、智谱 / Z.ai、Kimi / Moonshot、MiniMax、硅基流动 / SiliconFlow，分国内海外站）选一条填 key；或自定义供应商（地址、协议、key 自填）。都会先拉模型列表再选，选中的模型同时进「已激活」集合，设置界面里看得到勾选。

每屏「下一步」即落盘；`Esc` 上一步，`Ctrl+S` 跳过（只标记做过，别的一个字不写）。开场按 `Esc` 退出则下次还会再来。
`miyu init` 仍是非交互的脚本化初始化，**不**标记引导完成；升级上来的老配置在迁移里自动标成做过，不会被拦。

## 3. 第一次对话

裸运行 `miyu` 进入普通模式 REPL；开发预设另有子命令：

```bash
miyu           # 进入普通模式 REPL：Miyu 人格 + 全部工具
miyu dev       # 进入开发预设 REPL：无人格、极简工具，专注干活
```

也可以不进入 REPL，直接一句话提问：

```bash
miyu "今天天气怎么样"
miyu ask "帮我查一下美元汇率"
```

- 不带 `-c` 的一次性提问默认丢进**临时会话**，问完即弃。
- `miyu "..." -c` 把消息发进终端集成会话，保持上下文。
- `miyu --session 名字或编号 "..."` 发到指定会话。

## 4. 先做三件配置

打开配置 TUI：

```bash
miyu config
```

建议至少看这三处：

| 配置 | 为什么 |
|---|---|
| **供应商/模型 → 文本模型** | 默认是 opencode 公共模型；换成自己的 API 更稳、更私密 |
| **自定义提示词 → 用户身份** | 告诉 Miyu 你是谁，对话更沉浸 |
| **IM 平台 → QQ** | 需要接入 QQ 时才开；默认关闭 |

配置保存后，若 daemon 正在运行会自动热重载（`miyu reload` 手动也行）。

## 5. 最省事的三条启动路径

### 想在终端里聊天

```bash
miyu
```

输入内容后 Enter 发送；`/help` 看全部斜杠命令；`Ctrl+C` 中断；`Ctrl+D` 退出。

### 想在浏览器里用

```bash
miyu web
```

默认监听 `0.0.0.0:8300`，终端会打印局域网访问 URL。只在本机用建议：

```bash
miyu web --bind 127.0.0.1
# 第一次打开 WebUI:用内置账号登录(用户名 miyu,密码 miyu),按提示创建管理员账号(之后内置账号失效)
```

### 想在终端里像对空气说话一样提问（shell 集成）

fish 效果最完整，bash/zsh 支持单行：

```bash
miyu fish-init     # 或 bash-init / zsh-init
# 之后直接在终端输入自然语言即可；不想要了：
miyu remove-shell-hook
```
