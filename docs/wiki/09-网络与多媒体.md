# 09 · 网络与多媒体

> ⚠️ **临时版本提示**：本文档由 DeepSeek 根据当前 Miyu 源码逐行整理，属于临时参考版本；正式版文档仍在施工中，内容可能与最新代码存在出入。请以 `miyu -h`、`miyu config`、仓库 README 及源码为准。

## 1. 网络搜索（web_search）

### 数据源与回退链

配置了 key 时按这些供应商轮转：**Tavily → Firecrawl → AnySearch → Exa → SearXNG**。一个都没配时自动走：

```
Exa 免 key MCP 公共额度 → DuckDuckGo 爬虫 → Yahoo → 360 → 搜狗
```

- Exa 免 key 每日限量，报错/超额会自动冷却并回退。
- DuckDuckGo 被挑战页封锁 60 秒，搜狗反爬封锁 300 秒。
- 结果统一格式：标题 / URL / 摘要（Snippet 500 字符、Content 800 字符截断）。
- `max_results` 上限 10；Tavily/Firecrawl/AnySearch 请求 min 20，Exa min 10（为了信息量再裁剪）。

### 网页抓取（web_fetch）

- 只允许 http/https；Content-Length 超过 5 MiB 先拒，流式再限 5 MiB。
- `format=markdown|text|html`；默认最多返回 40000 字符，可调至 200000。
- 无结果缓存，只有失败冷却。

## 2. 搜图（search_web_images）

流程：多源并行搜索 → 候选排序 → 并发下载探针 → 图片校验 → 视觉模型安全审核 → 发布到本地。

- 来源：SearXNG（配了 base_url 必加）、DuckDuckGo、Bing CN；中文/大陆场景加百度、360（安全搜图时仅在视觉审核可用时启用）。
- 下载防 SSRF：禁代理、手动重定向 ≤8 跳、拒绝 localhost/私网/带凭据 URL、DNS 解析后固定 IP。
- 图片硬校验：魔数识别真实类型（不信 Content-Type）、≤16MP、解码成功、像素与头部一致。
- 安全与相关性：把候选拼成联系表发给视觉模型，`safe` 且 `relevance ≥ 55` 才收；审核不完整 fail-closed（不收）。
- 保存位置：`~/.miyu/data/pictures/web-images/`，按 sha256 去重复用。
- 默认 `max_download_mb=4`、`count=5`、`preview_count=1`。工具描述会要求模型把“一张/几张/多张”翻译成 1/3/5。

## 3. 识图（vision_analyze / print_image）

- `vision_analyze`：本地路径或 URL（本地 ≤10 MiB，jpg/png/webp/gif）。模型选择：显式 vision provider → 活跃多模态池 → opencode 默认 `mimo-v2.6-flash-free`。
- QQ 场景图片通过 `context_image_N` 引用，按 message_id 拉取；有缓存。
- `print_image`：终端里显示图片。原生 Kitty 终端用 Kitty 图形协议；否则调 `chafa`。默认占终端宽 45%、高 35%，上限跟 Kitty 占位记号表走（210 单元格）。
- 尺寸在**终端那一侧**解析：百分比要按用户终端的实际大小算，而 daemon 量到的不是它。模型显式给的 `width`/`height`/`size` 由 daemon 随图片事件带过去，缺省时才用配置百分比。所有会出图的工具（生图、看图、搜图预览、表情包）都走这条。
- 超时：响应头 15s、流空闲 20s、整图 60s（可配）。

## 4. 生图（generate_image）

- 默认关闭。配置：OpenAI 兼容（默认 `gpt-image-1`）或 RightCode，填 base_url/api_keys。
- 尺寸支持三套映射（RightCode / gpt-image / OpenAI 兼容）。
- 输出 `~/.miyu/data/pictures/generated-images/<prompt slug>-<时间戳>.png`。
- 工具会发图片事件；`auto_print` 开启时终端直接显示。出于安全，指令禁止模型在回复里直接贴本地路径。
- **通讯平台限额**：QQ 等平台会话中每条用户消息（含排队 follow-up）最多生成一张图，由代码强制（task-local 计数器），超额调用返回英文错误且不发 API；管理员与私聊白名单成员豁免；本地终端/WebUI 会话不限。生成失败会退还配额，同一请求内可重试。

## 5. Artifact（WebUI 专属工作区）

- `create_artifact` 把 AI 产出的文件放进 `~/.miyu/data/artifacts/<session_id>/`（目录 0700、文件 0600）。
- `present_artifact` 只在 WebUI 展示，`read_artifact` 读取，`apply_artifact_patch` 继续修改。
- 安全：文件名必须是单一普通路径分量、≤180 字符；所有读取 canonicalize 后必须仍在该会话目录内；拒绝 symlink。
